# film.mov

Фильмы и сериалы онлайн на телефоне, планшете и Android TV. На телевизоре всё управляется пультом, на телефоне пальцем. Без рекламы. Нужен Android 7.0 или новее.

## [⬇ Скачать film.mov](https://github.com/gamahacka/filmmov/releases/latest/download/filmmov.apk)

Ссылка всегда ведёт на последнюю версию. Скачайте файл и откройте его; если устройство спросит, разрешите установку из этого источника.

Обновления приходят сами: приложение предложит обновиться.
